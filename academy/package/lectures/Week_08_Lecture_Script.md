# Week 08: Quantum machine learning

## Instructor lecture script

Explain data encoding as a design choice, not a free operation. Introduce feature maps and fidelity kernels. Discuss variational quantum classifiers and gradient estimation. Compare quantum models with classical baselines using matched data splits and metrics. Emphasise data loading costs, trainability, generalisation and the absence of automatic quantum advantage.

## Suggested delivery
- Recorded lecture segments: 5–6 videos of 8–12 minutes each.
- Total recorded time: approximately 60–75 minutes for this week.
- Include a short pause for a worked example after each major concept.
- End with a 3-question retrieval-practice quiz.

## Key equations and concepts

- Use the equations and definitions in the corresponding lecture notes and notebook; explicitly define symbols before use.

## Instructor prompts
- Ask learners to predict the result before running the code.
- Ask what assumptions make the model valid.
- Ask what a classical baseline would be.

1. State the central concept in one sentence.
2. Identify one mathematical or computational assumption.
3. Name one limitation of the method.
