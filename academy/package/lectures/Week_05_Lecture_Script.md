# Week 05: Quantum search algorithms

## Instructor lecture script

Introduce the oracle model and query complexity. Explain the Deutsch–Jozsa promise problem, then Bernstein–Vazirani as a hidden-string problem. Derive Grover's oracle and diffuser as reflections that amplify marked-state amplitude. Demonstrate a tiny search problem and carefully distinguish asymptotic query scaling from practical runtime.

## Suggested delivery
- Recorded lecture segments: 5–6 videos of 8–12 minutes each.
- Total recorded time: approximately 60–75 minutes for this week.
- Include a short pause for a worked example after each major concept.
- End with a 3-question retrieval-practice quiz.
